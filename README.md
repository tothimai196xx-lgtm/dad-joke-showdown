# Dad Joke Showdown

Entry for the [make.fun bounty "Dad Joke Showdown"](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5): one dad joke, told out loud at the dinner table — a father, a step stool, and a cookie jar on the top shelf, with the punchline doing double duty at the very end.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (Node 22, stdlib only, no network, no dependencies).

## Entry (196 Unicode code points, 196 bytes)

> My son asked why I keep a step stool in the kitchen. I told him the cookie jar lives on the top shelf, the kids are still short, and in this family, son, if you want a cookie, you have to step up.

The joke is built on one clean turn: "step up" means both climbing the stool to reach the jar and rising to the occasion, so the pun lands on the first read and the punchline arrives at the very last words.
